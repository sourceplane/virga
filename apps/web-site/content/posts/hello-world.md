Welcome. This is the first issue of a newsletter that ships from a git
repository: every issue is a Markdown file, every send is a CLI command,
and the only thing running is a handful of Cloudflare Workers.

## What to expect

- One email when something ships. Nothing else.
- Every issue archived here, with a public view count.
- Unsubscribe in one click, no questions.

> Content is the configuration. The site renders the sections its folders
> fill, so the same tree is a newsletter, a portfolio or a directory.

See you in the next one.
